# Liquid Labyrinth 仕様

3D のマス目迷路を回転させ、重力で流れる液体（自分）を出口まで導くゲーム。

## 技術構成

| 項目 | 採用 | 理由 |
| --- | --- | --- |
| 描画 | Three.js (WebGL) | 3D・シェーダ・ポストエフェクトが揃い、Web のまま iOS (Capacitor) / Steam (Electron・Tauri) に包める |
| ビルド | Vite + TypeScript | |
| テスト | Vitest | 迷路生成の再現性・完全性を検証 |

## v0.1 で実装済み

### 迷路
- `N×N×N` のマス目（N = 3 / 5 / 7 / 9 / 11 / 13）。形状は立方体・球・ダイヤ（マスクで切り抜き）
- **Growing Tree 法の完全迷路**（閉路なし = 分岐した一本道の集合）
  - 掘り進めるマス: 82% 最新（長い通路）／ 18% ランダム（分岐）
  - 直進の重みを 0.3 に下げ、曲がり・ねじれを増やす
- **開始点は中央マス**。**出口は 1 つ**で、外壁に面したマスのうち中央から最も遠いマスに開く
- **シード**: 文字列 → xmur3 ハッシュ → mulberry32。整数演算のみなので端末が違っても同じ迷路になる
  - 乱数キーは `v{版}|{形状}|{N}|{シード}`。アルゴリズムを変えるときは `MAZE_VERSION` を上げる
  - URL `?seed=…&size=…&shape=…` で共有できる

### 液体（自分）
- 1×1 マス。迷路を回すと、迷路から見た重力方向が変わる
- 通れる方向のうち重力に最も沿った方向へ流れる
  - 静止中は内積 0.45 超で流れ出す／流れている間は 0.3 超で次のマスへ続く
  - 加速 (2.5 → 最大 9 マス/秒)、曲がり角で減速、行き止まりで着地
- 1 マス進む = 1 手（ターン）
- 表現はグラフィック設定で切替
  - Pixel: 小キューブ群 + 低解像度レンダリング
  - Smooth: 波打つローポリのブロブ（重力でつぶれ、進行方向に伸びる）

### 操作
- ドラッグ: 回転 ／ Shift+ドラッグ・右ドラッグ・2 本指ひねり・Q/E: ロール ／ ホイール・ピンチ: ズーム
- 矢印・WASD でも回転。離すと短い慣性
- R: やり直し ／ N: 新しい迷路 ／ Esc: 設定

### 表示
- 迷路は画面中央。外観は 3 種から選択（決めきれていないため切替式）
  - 半透明ガラス ／ 白いすりガラス（難）／ 透明 + 通路の骨格（易）
  - どの外観でも、液体の近くの壁だけ濃く見える
- **軌跡**: 通った経路が壁越しに見える。直近 N 手（設定 1–40、既定 8）を黄→ピンクで強調
  - Slid faces（既定）: 液体がすべった面（そのとき重力でもたれていた壁）だけをタイル状に塗る
  - Center line: マスの中心を結ぶ線
- **現在マスの表示**: 液体がいる（向かっている）マスから通れる方向をピンクの矢印で示す（マスの枠は描かない）
- **テーマ**: シアンの背景 + 白いローポリ。表記はすべて英語
- 演出: 着地のしぶき、ゴール時の紙吹雪、出口マーカーの明滅、効果音 (WebAudio 合成)

### 難易度
- **Easy（既定）**: 出口までの道を黄色い粒で表示 ／ 流れが遅い (最大 4 マス/秒) ／ 分岐マスで必ず一旦止まる
- **Normal**: ガイドなし・最高速
- 自己ベストは難易度ごとに別管理

### 画面構成
- 独自の UI 言語「Facet」（スマホ優先。定義は `src/style.css` 冒頭）
  - 面: 白い板の右上を斜めに切り落とす（ローポリの面取り）。影・ぼかし・グラデーション・角丸なしのフラットな塗り
  - 選択: 選んだマスに下から「液体」（青）が満ちる。スライダーのつまみはひし形
  - 文字: Outfit（npm で同梱）。ラベルは小さな大文字、数字は細く大きく
  - 色: インク（濃紺）+ 白 + 液体の青。黄色は出口と「進む」ボタン (Play / Next maze) だけ
  - 上: タイマー（1 文字ずつ固定幅なのでカウント中も幅が動かない）
  - 迷路の下: 手数とモード（難易度・サイズ・シード）。リプレイ中は再生バーに替わる
  - 右端: 縦並びのオプション（Restart / New / Mazes / Display）。スマホは右下・アイコンのみ、広い画面は右中央・ラベル付き
  - 幅・高さ 700px 以上ではパネルを中央に表示
- 起動時に Mazes パネル（難易度・サイズ・形状・シード → Play）。開いている間はタイマー停止
- Display パネルで外観・軌跡・グラフィック・強調手数・効果音を即時切替

### 進行
- 最初の操作でタイマー開始、出口から出た瞬間に停止
- 結果: タイム・手数・最短手数・自己ベスト（シード/サイズ/形状ごとに localStorage 保存）
- **ルート鑑賞**: 通ったルートを 3D で再生（再生/停止・シーク・速度）。自由に回して眺められる

## 今後のアップデート案

| 項目 | 方針 |
| --- | --- |
| 形状の追加（三角など） | `buildMask` に形状を足すだけで外殻・内壁は自動生成される |
| 液体を同時に 3 個 | 状態を配列化し、全員が出口に出たらクリア。マス占有の衝突ルールが要検討 |
| iOS アプリ | Capacitor で包む。`DeviceMotion` の重力ベクトルを `gLocal` に入れれば「傾けて操作」になる |
| Steam アプリ | Electron / Tauri で包む。Steamworks で実績・ランキング |
| アイテム | 1 マス掘る（`open` のビットを立てる）／出口から K マスの線を引く（`dist` を出口起点で計算）／液体を大きくする |
| ランキング | シード + 入力ログ（回転の時系列）を送ればサーバ側で再検証できる |
| 課金 | 外観スキン・液体スキン・デイリーシード以外の追加パックなど |
| ストーリー | 未定 |
